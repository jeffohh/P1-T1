#### Installation Instructions

###### System Requirements
- PC: Windows 10+ / macOS
- Tablet: Android / iOS (gyroscope required)

###### Steps to Install
1. Download the appropriate build (PC / WebGL / Tablet) from the project’s itch.io page.
2. PC: Extract the ZIP file → run Tank.exe.
3. Tablet: Install the APK (Android) or open the iOS app.

#### How to Play

###### PC Controls
- WASD → Move tank
- Spacebar → Fire shells

###### Tablet Controls
- Left virtual joystick → Move tank
- Right screen tap → Fire shells
- Tilt (gyroscope) → Control sliding ice block

###### Objective
- Survive for 2 minutes.
- Destroy more enemy tanks than the number of times you are destroyed.

#### Troubleshooting
- If the game doesn’t run, make sure the ZIP file is fully extracted before launching.
- On tablet, ensure gyroscope permissions are enabled.
- Update graphics drivers if you see crashes or visual glitches.
